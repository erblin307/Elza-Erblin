# Project Instructions

Smart Travel Planner is a Codex-owned implementation project. Keep these instructions active for every phase.

- Inspect existing files and current behavior before modifying code.
- Maintain one application and one coherent architecture; do not create duplicate implementations.
- Reuse and extend working components, tokens, domain types, and repository interfaces.
- Preserve the restrained, task-oriented design in `DESIGN_RULES.md`.
- Do not invent live integrations, bookings, recommendations, cloud sync, or other functionality.
- Keep React UI state out of persisted domain objects and storage access out of page components.
- Make bounded changes and do not modify unrelated features.
- Test, lint, build, and visually inspect relevant paths before reporting completion.
- Add a concise note to `docs/IMPLEMENTATION_NOTES.md` after each substantial phase.
